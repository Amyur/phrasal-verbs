# Phrasal Verbs Flashcards 🇬🇧

Interactive flashcards to practice and master English phrasal verbs. Built with HTML/CSS/JS and deployed via GitHub Pages.

## 🎯 Purpose

Daily practice tool for learning phrasal verbs in context — work, tech, and everyday situations. Designed for quick, focused sessions with real-world examples, not memorization lists.

## 🚀 Live Site

👉 [https://amyur.github.io/phrasal-verbs/](https://amyur.github.io/phrasal-verbs/)

## 📚 What's Inside

- Interactive flashcards with flip animation
- Phrasal verbs with definitions and examples
- English + Spanish translations
- Designed for data engineers / AI folks (tech & business contexts)

## 🛠 Tech Stack

- Vanilla HTML / CSS / JavaScript
- GitHub Pages for hosting

## 📖 Verbs Covered

`break into`, `pull off`, `carry out`, `roll out`, `set up`, `follow up on`, `narrow down`, `figure out`, `wing it`, `look into`, `take over` — and growing.
